# OiVox 主界面高还原实施指令

把下面内容作为一次独立任务交给 Codex。它把“像设计图”改成可核验的视觉、数据与交互约束，适合后续继续迭代主界面。

## 可直接使用的指令

> 只处理 OiVox 登录后无 TabBar 的 Main Hub。开始前完整阅读根目录及相关子目录的 `AGENTS.md`，检查工作区已有修改并保护无关文件。
>
> 视觉唯一基准是蓝湖画板“主界面 · 版本1”，画板尺寸 375×812 pt，image id `76ae2736-fedc-49ec-99fd-0292ec39f78e`。编码前必须确认画板和标注可访问，并输出设计审计表：逐项记录图层名称、x/y、宽高、字体、字号、字重、行高、字距、颜色、圆角、阴影、旋转、层级、切图来源和交互。关键页面或标注不可读时停止视觉实现并列出缺失项，不得凭感觉补画。
>
> 资源优先级：项目已有蓝湖切图 > 蓝湖可导出切图 > 项目已有同款本地资源 > 按标注制作的本地 SVG。不得用 emoji、Unicode 符号、远程运行时 URL 或临时 CSS 图形替代正式图标。若蓝湖不能导出简单矢量，允许制作等比例本地 SVG，但必须在交付报告中单独列出。
>
> 保留已有账户、每日推荐、关系、金币、消息与本地持久化逻辑，不要为视觉还原另建一套数据。首页 New voices 必须直接读取当天稳定的 7 位推荐用户；头像、国旗和音频使用本地资源；隐藏字段不进入展示模型。主页查看或播放不消耗卡片，喜欢不等同好友。
>
> 首先按 375×812 实现：背景渐变、品牌区、金币、好友请求徽标、头像、标题、说明、两张错位真人照片卡、手写注释、Now playing 浮层和 New voices 横向卡片的全部尺寸、位置与层级以标注为准。所有可点击控件有效触摸区域不小于 44×44pt。初始画面不得出现蓝湖没有的 TabBar、消息列表、四宫格或占位高度。
>
> 交互必须真实连接状态：金币进入金币/设置入口；请求徽标进入好友请求；头像进入本人资料；人物卡进入对应稳定 userID 的资料；消息、好友、设置和语言继续沿用蓝湖定义的入口层级，不在初始主界面擅自增加按钮。播放条支持播放、暂停、进度、结束、错误与重试；同一时间只播放一条，页面隐藏、离开或销毁时停止并释放。异步操作包含 busy、disabled、失败、取消和清理，连续点击不得重复导航或重复提交。
>
> 保持 Vue 3 + Vite + JavaScript + CSS 和现有 Native Bridge，不增加框架、状态库、手势库或第二套 Bridge。页面只有一个主纵向滚动容器。支持 safe area、`100dvh`、`prefers-reduced-motion`、320×568、375×667、375×812、390×844、393×852、430×932。八语言 key 完整；阿拉伯语和希伯来语根节点为 RTL，方向布局镜像，但品牌、金额、国旗、头像、语音波形和媒体控制保持正确方向。
>
> 完成后对 375×812 与蓝湖原图进行并排或半透明叠加比较，至少执行两轮修正；再生成六个规定视口截图，检查横向滚动、白边、文字溢出、卡片裁切和 Home Indicator。运行 Vitest、Vite 生产构建、WebApp 同步和 Xcode 模拟器构建。最后自查远程资源、TabBar 残留、无效按钮、音频清理、RTL 和 reduced motion。未进行真机验证必须明确说明。
