# OiVox 推荐、安全与 Voice Earth 统一逻辑

## 1. 产品规则

- 推荐资格只包含：非本人、内容可见、允许展示语音、存在有效语音、不是好友、没有待处理好友请求、双方均未处于拉黑状态的用户。
- 每个账户按设备本地日期每天获得 7 个免费推荐机会。同一天内列表稳定，重进页面、切换语言和重启 App 不重新发放。
- 喜欢并划走、跳过、发送好友请求或拉黑都会让当前用户退出当天可操作推荐；不能通过取消请求、解除拉黑、重进页面或重启 App 刷新免费额度。
- 免费机会用完后，用户可明确确认使用 50 金币兑换 5 个当日推荐。只有能够一次提供 5 个合格用户时才扣币。
- 金币推荐只在交易记录的 `dayKey` 当天有效，次日本地零点后失效；次日重新分配免费 7 人。
- Voice Earth 的访问权由当前账户是否已经发布自己的 7 秒语音决定，与金币余额、推荐剩余数量无关。
- 拉黑优先级最高：拉黑用户不再出现在主页、Voice Earth、推荐、好友、请求、消息列表或可发起通话的入口中。
- 解除拉黑仅解除安全限制。历史消息作为本地审核证据保留，但不自动恢复好友、请求、点赞、未读数或当天推荐。

## 2. 状态机

| 当前状态 | 用户动作 | 下一状态 | 额度/金币结果 |
| --- | --- | --- | --- |
| Voice Earth 锁定 | 发布自己的 7 秒语音成功 | 已解锁 | 不扣金币 |
| 免费推荐可用 | 喜欢并划走 / 跳过 | 下一张免费推荐 | 免费剩余 -1 |
| 免费推荐可用 | 发送好友请求 | 进入待确认关系并退出推荐 | 免费剩余 -1 |
| 任意推荐可用 | 拉黑 | 安全隔离并退出所有入口 | 当前机会消耗，不补发 |
| 免费推荐为 0 | 确认兑换 5 人且余额充足 | 5 个额外推荐可用 | 扣 50 金币一次 |
| 免费推荐为 0 | 余额不足 | 金币不足弹窗 | 不扣金币，可进入内购 |
| 任意状态 | 本地日期变化 | 新的一日 | 额外推荐失效，重新分配免费 7 人 |
| 已拉黑 | 解除拉黑 | 普通陌生人 | 不恢复好友，不在当天重新推荐 |

## 3. 页面布局与数据职责

### 主页面

- 顶部只显示账户级金币和消息未读数。
- 推荐拼贴、Now Playing 和 New voices 都来自同一个当天推荐快照；剩余推荐优先排在已处理推荐之前。
- New voices 标题下显示“免费剩余”或“额外剩余”，不再用金币图标冒充推荐数量。
- 页面从推荐或社交子页面返回时，必须重新读取社交、金币和推荐持久化状态，避免拉黑或购买后的旧数据闪回。

### 推荐卡页面

- 顶部额度区分免费剩余与金币兑换的额外剩余。
- 卡片操作和底部操作栏只在存在可展示对象时出现。
- 当天机会耗尽或所有已分配对象因安全关系被移除时，只展示单一空状态和“50 金币获取 5 人”入口。
- 金币不足进入金币不足弹窗；购买金币返回后回到原确认上下文，不自动扣 50 金币。

### Voice Earth

- 未发布本人语音时展示锁定页，唯一主操作是录制并发布 7 秒语音。
- 已解锁时只显示当前仍可操作的推荐用户；地区筛选只改变显示，不改变额度。
- 当日推荐为空时展示完成状态和获取更多入口，不显示已经拉黑或已移出的头像。

### 拉黑名单

- 拉黑动作保留二次确认，并先完成 Native 安全记录，再提交 H5 业务状态。
- 若 H5 持久化失败，尝试回滚 Native 拉黑，避免两层状态分裂。
- 解除拉黑同时更新 Native 和 H5；失败时保留原拉黑状态并允许重试。

## 4. 持久化矩阵

| 数据 | 所有者 | 作用域 | 生命周期 |
| --- | --- | --- | --- |
| 社交关系、请求、会话、举报 | `socialStore` | accountID | 登出保留，账户隔离 |
| 每日 7 人、决策、当天抑制名单 | `discoveryStore` | accountID + local day | 次日滚动，账户隔离 |
| 金币余额、消费与内购交易 | `coinWalletStore` | accountID | 持久保留，幂等交易 ID |
| Voice Earth 解锁 | `voiceEarthAccess` | accountID | 发布成功后保留 |
| Native 拉黑集合 | `SafetyStore` | device | 通过 Bridge 与 H5 同步 |

## 5. 路由矩阵

| 来源 | 目标 | 返回后必须恢复 |
| --- | --- | --- |
| 主页面推荐 | 推荐卡 | 最新剩余数、卡片顺序、金币余额 |
| 主页面 See all | Voice Earth | 主页面滚动和音频停止状态 |
| Voice Earth 头像 | 推荐卡 | 返回主页后重新计算可见推荐 |
| Voice Earth 锁定页 | 个人语音录制 | 发布后解锁，返回个人页/主页 |
| 推荐耗尽页 | 金币确认 / 内购 | 原推荐上下文和确认状态 |
| 用户资料/聊天/通话 | 举报与拉黑 | 成功拉黑后退出目标用户页面 |
| 设置 | 拉黑名单 | 解除拉黑后即时移除该行 |

## 6. Native Bridge 矩阵

| Service.Method | 参数 | 成功结果 | 失败恢复 |
| --- | --- | --- | --- |
| `Safety.blockUser` | userID, operationID | blocked=true | 不提交 H5 拉黑，可重试 |
| `Safety.unblockUser` | userID, operationID | blocked=false | 保留 H5 拉黑，可重试 |
| `Store.purchase` | productID | 已验证交易 | 取消/延迟/失败均不加币 |
| `VoiceRecorder.publish` | assetID | published=true | 保持 Voice Earth 锁定并允许重试 |

## 7. 受保护行为

- 不改变登录、注册、EULA、账户接口和 Token 行为。
- 不删除历史消息、举报或交易记录。
- 不把浏览器模拟购买当成真实支付。
- 不允许任何重复点击造成重复扣币、重复请求或重复拉黑。
- 八种语言使用稳定 ID 判断状态；阿拉伯语和希伯来语只镜像布局，不改变业务判断。
